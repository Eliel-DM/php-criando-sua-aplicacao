# 🎓 Trilha PHP - Alura

Repositório com os projetos e exercícios desenvolvidos durante o curso de PHP da Alura. O foco principal é a prática de conceitos fundamentais da linguagem como variáveis, tipos de dados, estruturas de controle, arrays, loops e manipulação de entrada/saída.

---

## 📂 Arquivos do Projeto

### [screen-match.php](screen-match.php)
Sistema de cadastro e avaliação de filmes. Calcula a média de notas de um filme a partir de argumentos passados via terminal, determina o gênero com base no nome utilizando `match`, e classifica o filme por ano de lançamento utilizando `if/elseif/else`. Também demonstra uso de arrays e `var_dump`.

### [controle-de-saldo-bancario.php](controle-de-saldo-bancario.php)
Sistema interativo de controle bancário com menu no terminal. Permite consultar saldo, sacar (com validação de saldo insuficiente), depositar valores e sair do programa. Utiliza `while` para o loop principal, `switch` para navegação e `fgets(STDIN)` para entrada do usuário.

### [manipule-os-dados.php](manipule-os-dados.php)
Primeiro contato com variáveis e tipos em PHP. Define dados de um filme (nome, ano, nota, inclusão em plano), realiza operações aritméticas para calcular a média de notas, e utiliza concatenação e interpolação de strings para exibir os resultados formatados.

### [lista-de-exercicios.php](lista-de-exercicios.php)
Lista de exercícios da primeira parte do curso. Contém 5 programas:
1. Exibição de nome na tela
2. Cálculo de média de três notas
3. Conversão de metros para centímetros
4. Verificação de ano bissexto
5. Conversão de temperatura Celsius para Fahrenheit

### [lista-de-exercicios2.php](lista-de-exercicios2.php)
Lista de exercícios da segunda parte do curso. Contém 3 programas:
1. Exibição de todos os números ímpares de 0 a 100 usando `for`
2. Cálculo de IMC com classificação
3. Saudação baseada no horário (bom dia, boa tarde, boa noite)

### [lista-de-exercicios3.php](lista-de-exercicios3.php)
Lista de exercícios da terceira parte do curso. Contém 4 programas:
1. Remoção de elementos duplicados de um array
2. Percorrimento de array de notas com aprovação/reprovação (nota > 6)
3. Array associativo representando contas bancárias com titular e saldo
4. Array de familiares com adição de novos elementos (idade)
